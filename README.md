# Klimaatbeleid vs. Realiteit

Een Streamlit-dashboard waarin onderzocht wordt in hoeverre de transitie naar hernieuwbare energie leidt tot een daling van CO₂-uitstoot in relatie tot het inkomensniveau van landen.

## 📊 Datasets & Bronnen
* **CO2 Emissions Across Countries, Regions & Sectors** (Kaggle / Our World in Data)
* **Renewables Share 2000-2025** (Kaggle / Our World in Data / Ember)

## 🛠️ Vereisten & Installatie
Om het dashboard lokaal te draaien:
```bash
pip install -r requirements.txt
streamlit run app.py
